Age Of Empires – RT56 Edition

This is the standalone all-in-one build. It contains The Road to 56, Age Of
Empires and the dedicated compatibility layer in one resolved load order.

Enable only this mod. Do not enable The Road to 56, the separate Age Of Empires
mod or the old compatibility layer alongside it.

Always begin a new game after updating this edition.

The supported scenario is Time of Upheaval, beginning on 1 January 1936.
The inherited 1939 bookmark remains in the package for menu compatibility but
is not a supported Age Of Empires campaign start.

Release validation can be run from the mod directory with:
    python tools/validate_aoeiw.py
